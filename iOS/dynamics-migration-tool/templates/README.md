# iOS Migration Templates

These templates are optional accelerators for recurring migration edits.

- `swiftui-scene-auth-bridge.swift.template`:
  SwiftUI + SceneDelegate authorization bridge for SDK-managed window flow.
- `info-plist-manual-required-keys.xml.template`:
  Required manual Info.plist key block when switching from generated plist mode.

Template usage is guidance-only. Always adapt to app architecture and keep
`[BB_DYNAMICS-MIGRATION]` comments on migrated code.
